⚙️ Sozlamalar

Google Safe Browsing API kalit

Saytlarni Google'ning global qora ro'yxati orqali tekshirish uchun bepul API kalit kerak. Kalit faqat sizning brauzeringizda saqlanadi.

📖 API kalit qanday olinadi:
  1. console.cloud.google.com saytiga kiring
  2. Yangi loyiha yarating
  3. "APIs & Services" → "Library" → "Safe Browsing API" → Enable
  4. "Credentials" → "Create Credentials" → "API key"
  5. Olingan kalitni shu yerga yopishtiring
🔒 Sizning API kalitingiz faqat brauzeringizning lokal xotirasida (localStorage) saqlanadi. Hech qaerga yuborilmaydi, hech kim ko'ra olmaydi.
